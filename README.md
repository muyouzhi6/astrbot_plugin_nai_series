# Nai系列生图

给 AstrBot 使用的 NAI 4.5 / NAI 5 生图插件. 两套模型拥有独立的画师串、负面词、默认预设和生成参数, 可以在同一个会话交替使用. 配置好的模型名会原样传给图片接口, 不会被隐藏的版本逻辑改写.

## 开始使用

1. 在 AstrBot 插件管理中通过仓库地址或 ZIP 安装. 要求 AstrBot >= 4.28.1, Python >= 3.12.
2. 在插件配置中填写图片连接地址和密钥. 只需地址和密钥, 无需选择服务商品牌或接口模式.
3. 按需填写翻译接口地址、密钥、模型. 已有英文标签可在指令末尾添加 `--raw` 跳过翻译.
4. 在可视化预设列表中分别添加 NAI 4.5 和 NAI 5 预设, 填写预设名称、画师串、负面词. 将对应名称填入两套默认预设.
5. 发送 `/nai4 描述` 或 `/nai5 描述`.

支持配置多个连接. 根据地址自动识别 OpenAI Images 和官方图片协议. 当前版本只在接口明确拒绝认证、权限或路由不存在时尝试下一连接; 超时、服务器错误和下载失败不会自动重新提交付费任务.

常见地址:

```text
https://meinianda.top/v1
https://love.auroralove.cc/api/v1
https://image.novelai.net
```

美年达站点参考价格: NAI 4.5 为 0.013/张, NAI 5 为 0.13/张. 价格与计价单位以站点实时说明为准.

## 指令

| 指令 | 功能 |
| --- | --- |
| `/nai4 描述` | 使用 nai4 模型配置, 默认 `nai-diffusion-4-5-full` |
| `/nai5 描述` | 使用 nai5 模型配置, 默认 `nai-diffusion-5-full` |
| `/预设 nai5 风格名` | 切换当前用户在当前会话的 NAI 5 预设 |
| `/预设nai4 风格名` | 切换 NAI 4.5 预设, 支持无空格指令别名 |
| `/预设 nai4 none` | 本会话停用画师预设, 使用该模型默认负面词 |
| `/nai预设` | 将各预设及已绑定展示图绘制成图册, 不调用生图 API |
| `/nai预设 nai5 2` | 只看 NAI 5 预设的第 2 页, 每页 6 张卡片 |
| `/nai预设展示 nai5 风格名` + 图片或引用图片 | 绑定/覆盖预设展示图, 仅管理员 |
| `/nai预设试画 nai5 风格名` | 用该预设的样图描述付费生成一张, 自动保存为展示图, 仅管理员 |
| `/nai模型 完整模型名` | 设置 `/nai生图` 使用的模型 |
| `/nai生图 描述` | 使用当前用户在当前会话选择的模型 |
| `/nai状态` | 查看两套模型、预设、尺寸、步数和负面词长度 |
| `/nai重绘` | 用上一次实际提交的完整 prompt 和参数重新随机生成, 不重新翻译 |
| `/nai参数` | 查看自己上次实际提交的模型、尺寸、步数、正向和负面词 |
| `/nai取消` | 取消本地等待; 已提交上游的任务可能继续生成和计费 |
| `/nai帮助` | 查看指令与参数 |

指令前缀遵循 AstrBot 配置. 若你的唤醒前缀为 `.` 则使用 `.nai5 描述`.

### 单次参数

把选项放在描述后, 不会改动默认配置:

```text
/nai5 一只橘猫坐在窗边 --preset 电影感 --size 832x1216 --steps 28 --scale 5
/nai4 1.5::watercolor::, a cat --raw
/nai4 一只橘猫 --model nai-diffusion-4-5-curated
```

`--model` 不允许将 `/nai4` 改成 NAI 5, 也不允许将 `/nai5` 改成 NAI 4.5. 这两条指令的完整模型名也可以分别在后台改成所属模型族的 Curated 版本. 任意其他模型使用 `/nai模型` 和 `/nai生图`.

## 预设和状态

- 每个预设包含画师串和负面词. 预设所属模型族决定能在哪条指令使用, 不覆盖实际模型名.
- 预设负面词为空表示明确使用空负面词; 停用预设后使用模型的默认负面词.
- 同名预设可分别存在于 nai4 和 nai5. 绑定展示图时遇到重名须明确模型族.
- 每次生图读取最新预设文字. 排队中的请求使用提交时的快照, 防止执行中更换预设影响其他任务.
- 设置按用户 + 会话保存, 不会因群友切换预设串到自己, 重载和重启后仍保留.
- 稳定 ID 自动生成, 保留 ID 后可重命名预设而不丢失展示图. 删除已选预设时明确报错, 不偷偷选别的风格.
- 展示图、会话状态和上次参数保存在 `data/plugin_data/astrbot_plugin_nai_series/`, 更新插件不会覆盖.
- 图册依赖系统中文字体. Linux 可安装 Noto Sans CJK 或文泉驿, 也可指定 `gallery_font` 文件.

## 翻译

默认忠实转换主体、动作、数量、关系、服装和尺寸, 不凭空补外貌、镜头、天气或场景. 数值如“一米高”保留成明确英文短语. 画师串单独拼接, 不交给翻译模型重写.

可以设置独立的翻译模型, 完全替换 `translator_system_prompt`, 或追加自定义前缀. 翻译是单轮请求, 不携带群聊历史. 模型返回空文本、截断或拦截时停止生图, 不静默改用原文并收费. `--raw` 直接使用用户给出的 prompt.

自定义提示词用于翻译规则调整, 不能保证改变模型服务端的内容限制. 插件不内置把年龄或同意状态改写成其他含义的提示词.

## LLM 调用

`enable_llm_tool` 默认关闭. 开启并重载后注册两个独立工具:

- `nai4_generate_image(prompt, preset?)`
- `nai5_generate_image(prompt, preset?)`

工具说明要求仅在用户明确要生图时调用, 保留原文, 不编造预设名, 不混用模型. 工具与手动指令共用权限、队列、冷却和发送流程. 工具只有在图片发送调用完成后才返回成功. 关闭时不注册工具, 不向 LLM 暴露无效能力.

## 并发与费用

默认最多并发 2 个请求, 队列总容量 10, 每用户每会话同时最多一个任务, 冷却 10 秒. 可设仅管理员或用户白名单. 绑定展示图和试画仅管理员可用.

Images 请求不自动传 seed, 避免部分中转把字符串随机种子改成数字导致 422. 重绘保留其他参数但使用新随机种子, 不提供固定 seed 复现保证. 图片发送失败不会自动重新生成. 命令和日志都不会回显密钥.

## 验证范围

2026-09-25 在两条上述兼容连接分别实测 NAI 4.5 和 NAI 5. 四张图片的 PNG Source 分别为 NovelAI Diffusion V4.5 / V5, 尺寸均为 832x1216, 步数分别为 23 / 28, prompt 与负面词符合请求.

官方适配器实现原始模型名传递、`/ai/generate-image`、200/201、ZIP/JSON/SSE 最终图片解析. 已用模拟协议测试, 尚未使用官方账号密钥完成真实出图. 官方公开 OpenAPI 的模型枚举较旧, 不据此把新版模型映射成旧版.

平台收图仍以用户实际会话结果为准, API 出图测试不等于 QQ 端到端测试.

参考 AstrBot 官方插件文档、BestNAI 的原有工作流及 lifeschedule 的衣柜展示交互. 本插件独立实现, 不修改 AstrBot Core, 不附带个人密钥或私有预设.
